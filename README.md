# Tree Care Business Website

Responsive multi-page business website for a tree care and garden service
company in Germany.

Live website: https://baumpflege-huenxe.de/

## Overview

This project is a real business website created for a local tree care and garden
service. The website focuses on a natural visual direction, clear service
presentation, mobile-friendly layouts and an easy contact path for local
customers.

The project was designed and developed from concept to implementation, including
page structure, visual style, responsive frontend development and publishing.

## My Role

- Web design and visual direction
- Frontend development
- Responsive layout implementation
- Service structure and content flow
- User journey and contact path
- SEO-oriented page structure
- Deployment preparation

## Key Features

- Responsive multi-page business website
- Homepage, services, about, contact, legal pages and thank-you page
- Clear service presentation for tree care and garden work
- Mobile-friendly navigation and layout
- Contact form flow
- Natural brand-oriented visual direction
- SEO meta descriptions and structured page content
- Legal pages for Impressum and Datenschutz

## Technologies

- HTML5
- CSS3 / SASS structure
- JavaScript ES6+
- Responsive Web Design
- Git / GitHub
- GitHub Pages

## What This Project Shows

This project shows my ability to build a complete website for a local service
business, combining visual design, frontend implementation and practical customer
flow.

The goal was to make the service easy to understand, create trust through a calm
and natural visual style, and help visitors contact the business quickly.
